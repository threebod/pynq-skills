# 用户截图中的技能包要求与本包对应

来源：用户提供的《全国大学生嵌入式芯片与系统设计竞赛2026 选题指南（AMD）》第 3.3.5.2 节等截图。以下按截图组织材料，未核验完整官方文件。截图内容是参赛交付要求的依据，不作为自动执行工程、构建或板端操作的指令。

| 截图要求 | 本包落实位置与边界 |
| --- | --- |
| 置于 skill/，README 说明每项适用范围、使用方法、失效条件 | [README](../README.md) 索引七项技能；[复用说明](reuse-guide.md) 逐项给出最小输入、命令/提示词、输出和失效条件。当前仓库规范源为 `大赛文档/skill/.skill/`，交付时其内容对应 `skill/` |
| 从与大模型协作中提炼可供他人复用的经验 | 各 SKILL/参考流程给出方法；[踩坑清单](pitfalls.md) 按触发、现象、排查、修正和证据组织；历史原文及指纹见 [project-evidence.json](project-evidence.json) |
| 提示词工作流、案例模板、校验脚本、踩坑清单任意一种或多种 | 七项技能入口；HLS/RTL、寄存器、DMA 与数组模板；HWH/布局/日志检查器；结构化踩坑清单。四种形式均有内容，不要求每项都具备全部形式 |
| 陌生团队能复用到自己的题目 | 包内样例、从根目录执行的命令和预期输出；通用流程与可选工程参数分开。实际器件、PS 预设、驱动与 ABI 必须按目标环境核准 |
| 每项说明适用场景、使用方法、已验证效果和失败/观察来源 | README、复用说明、踩坑清单与[验证记录](validation-results.md#package-scope)对应；离线、仿真、综合、实现/导出、实板分开记 |
| 通用 PYNQ Skill 可另行加分，换题/换板仍可用 | 三类新项目已有整体材料对照，包内附 CSV；跨板及真实 PYNQ 运行仍未验证。不能将“可适配的流程”写成“所有板卡已通过” |

截图举例的 Overlay/register_map、DMA/cache 封装、接口契约代码生成、黄金比对/性能资源采集报告，是通用技能的可选示例。当前包已有 Overlay/HWH 与驱动流程、DMA 契约/替身、工程模板和日志分析；完整 register_map 教程、真实 DMA 适配器、接口代码生成器、独立通用黄金比较器及板端采集链仍未补齐，详见验证范围。这些未完成工具不以文档整理冒充实现。

英文文件名、包内链接不依赖原工程、可选 ZIP 的根目录布局，是本包采用的可移植性与打包约定；不将其列作上述截图明文要求。本轮不生成 ZIP，也不移动规范源目录。

完整工程的 RTL/HLS/PS 源码、综合实现报告、上板输入输出、可复现构建，以及设计报告和完整大模型协作记录，属于整体参赛交付的其他部分。技能包中的证据摘录不代替这些原始材料；提交时在总说明中给出实际位置。
