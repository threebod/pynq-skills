# 新板与镜像分支

默认使用现有 PYNQ 镜像。只在实际需求要求新板支持、驱动缺失或现有镜像不兼容时进入此分支；先定位具体缺口，不把重建内核/rootfs 当成通用修复。

| 层次 | 必要核准 |
| --- | --- |
| 器件/架构 | 实际 part、Zynq-7000/MPSoC 差异；本模板 PS7 Tcl 不能直接用于 MPSoC/Versal |
| 板级配置 | 同板原理图、DDR/MIO/时钟/复位/供电、原始约束与许可；不移植其他板引脚 |
| 系统 | 板卡 BSP、内核配置、设备树/中断控制器/UIO、PYNQ 与 Python 版本对应关系 |
| 数据接口 | DMA/HP/一致性与地址位宽、缓存同步、资源独占；不能套裸机固定地址 |
| 制品/启动 | 工具版本、BOOT 与 BIT/HWH/XSA 对应、现有镜像备份/回退和启动介质身份 |
| 验收 | 从干净目标环境复现导入、轮询、IRQ、退出/异常和冷启动；保留实际输出 |

如果确需构建镜像，按目标 PYNQ release 的官方 sdbuild/板卡定义流程核对 host OS、PetaLinux/Vivado 版本及 BSP 来源，再单独确定构建和写卡范围。不要直接执行网络脚本或用最新 master 的镜像覆盖旧板。

本包提供分支检查表，没有替每种板卡生成 BSP、设备树或镜像；这部分应在实际选定的板卡/版本上补充验证。

入口：[PYNQ 官方项目与对应 release](https://github.com/Xilinx/PYNQ)、[PYNQ 2.6.1 文档](https://pynq.readthedocs.io/en/v2.6.1/)。
