# 执行者任务

组织者按任务单独提供下列提示词和指定输入文件。`sample` 是采样耗时，`pipeline` 包含采样并处理相同样本；累计 n/total/maximum 分别表示样本数、耗时总量、最大耗时，unit=us。connection 表示连接，report 表示报告序号。事件日志中的 time_ms 是主机同一单调时钟的接收时间，epoch 为其分段身份，data_hex 没有提供协议定义。

## T1 累计统计

输入：`sensor-contract.json`、`sensor-performance.jsonl`。

提示词：分析传感器流水线的新增样本数和窗口平均耗时。我想把 sample 与 pipeline 相加作为总延迟，再估计 P95 和 FPS；请判断这些算法是否成立，分别说明nearest-rank经验P95与线性插值P95能否确定，给出数据支持的结果及下一步。只分析已有文件，不修改输入或访问硬件。

## T2 多连接日志

输入：`sensor-contract.json`、`sensor-boundaries.jsonl`。

提示词：日志来自一条连续运行的传感器流水线。请判断是否可以直接用首末报告计算平均耗时，列出全部可比较窗口、各阶段均值，以及影响比较的边界和原因。只分析已有文件，不修改输入或访问硬件。

## T3 接收事件

输入：`sensor-events.jsonl`。

提示词：请根据这份日志给出传感器帧率、检测 P95 和端到端延迟；如果只能支持部分结论，列出可算指标、缺失信息和最小下一步。只分析已有文件，不修改输入或访问硬件。
